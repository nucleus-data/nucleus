# Nucleus v0.2.0 — Release Readiness Checklist

> One-page operational checklist for the v0.2.0 public launch. Sequenced top-to-bottom: each phase gates the next. **(founder)** = founder-gated, no auto-fire. All other items are CI-fired or local verification commands. Full runbook: [`v0.2_FOUNDER_CLOSE_CHECKLIST.md`](v0.2_FOUNDER_CLOSE_CHECKLIST.md). Launch-kit artifacts (Show HN headlines, social posts) live in [`launch_kit/`](launch_kit/).

## Phase 1 — Pre-tag prep

- [ ] **(founder) PyPI Trusted Publisher pre-registered** at <https://pypi.org/manage/account/publishing/> — owner `nucleus-data`, repo `nucleus`, workflow `release.yml`, environment `pypi`. First tag push fails without this. Docs: <https://docs.pypi.org/trusted-publishers/using-a-publisher/>.
- [ ] **(founder) GitHub `pypi` environment exists** — Settings → Environments → New → `pypi` (referenced by `release.yml` job `publish-pypi`).
- [ ] **(founder) `nucleus-data/nucleus` repo URLs resolve** — verify `gh repo view nucleus-data/nucleus`.
- [ ] **`pyproject.toml` version is `0.2.0`** — `rg '^version = ' pyproject.toml` returns `version = "0.2.0"`.
- [ ] **`CHANGELOG.md` `[0.2.0]` section dated `2026-05-15`** — `rg '^## \[0\.2\.0\]' CHANGELOG.md`.
- [ ] **All 11 governance scripts exit 0 locally** — `python scripts/check_vocabulary.py` + `check_pinning.py` + `loc_budget.py` + `dagster_leak_check.py` + `check_error_codes.py` + `check_api_stability.py` + `check_layering.py` + `check_licenses.py` + `check_install_size.py` + `check_lazy_imports.py` + `check_changelog.py`.
- [ ] **Pytest green** — `pytest tests/ poc/ -m "not integration and not slow" --no-cov -q` (expect 850+ passed / 0 failed).
- [ ] **WSL beachhead E2E 8/8 PASS** — run `python scripts/beachhead_e2e.py` inside WSL. Real Iceberg snapshot ID > 0; zero forbidden classnames.
- [ ] **Cold install <60 s in fresh venv** — `python -m venv .venv-smoke && .\.venv-smoke\Scripts\Activate.ps1 && Measure-Command { pip install -e . }`.
- [ ] **`python -m build && python -m twine check dist/*` PASS** — produces `nucleus-0.2.0-py3-none-any.whl` + `nucleus-0.2.0.tar.gz`. Inspect: `python -m zipfile -l dist/nucleus-0.2.0-py3-none-any.whl | Select-String 'venv|.scratch|.pytest_cache'` returns zero hits.
- [ ] **(founder) Tag corruption recovered** — local `v0.1.0` + `v0.2.0` deleted, remote `v0.1.0` deleted from `mtoanng` mirror per close-out §1.6. Verify: `git tag -l | Select-String '^v0\.'` empty.
- [ ] **(founder) Release notes reviewed** — read [`v0.2.0_RELEASE_NOTES.md`](v0.2.0_RELEASE_NOTES.md); confirm tone, accuracy, empirical numbers match `docs/internal/benchmarks/2026-05-15_baseline.md`.
- [ ] **CI green on `main`** — `gh run list --workflow=ci.yml --branch=main --limit=1` shows `success` (5 jobs: lint, governance, test matrix, upgrade-smoke, beachhead-e2e).

## Phase 2 — Tag + push (founder-gated, AGENTS.md §3)

- [ ] **Stage final release commit** — `git add CHANGELOG.md pyproject.toml AGENTS.md && git status --short` (≤3 files).
- [ ] **Commit** with `release: v0.2.0 — Workbench v0.3 + Wave 2 reliability + Iceberg branch/tag CLI` (full message template in close-out §4.4).
- [ ] **Push commit** — `git push origin main` (refuses force-push per AGENTS.md §3).
- [ ] **Create annotated tag** — `git tag -a v0.2.0 -m "Nucleus v0.2.0 — Public Launch ..."` (full message in close-out §4.5).
- [ ] **Push tag** — `git push origin v0.2.0`. **This is the moment of public commitment.**
- [ ] **Verify tag on GitHub** — `gh api repos/nucleus-data/nucleus/git/refs/tags/v0.2.0` returns the tag SHA.

## Phase 3 — Watch PyPI publish workflow (auto-fired by tag push)

- [ ] **Workflow run triggers within 60 s** — `gh run watch --repo nucleus-data/nucleus`. Total runtime ~6–8 min.
- [ ] **Job `build` green** — version-consistency check, governance × 9, pytest, `python -m build`, `twine check` (release.yml lines 42–143).
- [ ] **Job `publish-pypi` green** — OIDC publish via `pypa/gh-action-pypi-publish@release/v1` (no API token). If FAIL with "publisher not configured": re-run after registering at <https://pypi.org/manage/account/publishing/>.
- [ ] **Job `create-release` green** — GitHub Release page auto-created with CHANGELOG body + wheel + sdist as assets.
- [ ] **PyPI artifact live** — `pip index versions nucleus` lists `0.2.0`; <https://pypi.org/project/nucleus/0.2.0/> shows wheel + sdist + rendered README.
- [ ] **Cold PyPI install smoke** — `python -m venv .venv-pypi && .\.venv-pypi\Scripts\Activate.ps1 && pip install nucleus==0.2.0 && nucleus version` returns `0.2.0`.
- [ ] **(founder) Replace auto-generated Release body with curated notes** — `gh release edit v0.2.0 --notes-file docs/release/v0.2.0_RELEASE_NOTES.md`.
