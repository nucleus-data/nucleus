# Code of Conduct

Nucleus follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Summary

Be kind, be constructive, be inclusive. We will not tolerate harassment, discrimination, or bad-faith behavior in any form.

## Reporting

Report violations to the project maintainers via a private GitHub message or by emailing the address listed in the repo `SECURITY.md`. All reports will be handled confidentially.

## Scope

This code of conduct applies in all project spaces — GitHub Issues, Discussions, Pull Requests, and any community spaces.

## Full text

The full Contributor Covenant v2.1 text is at [contributor-covenant.org](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
