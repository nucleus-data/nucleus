# Solo-Founder Handover

**Audience**: The founder, future-self, 6+ months after the v0.2.0 public launch.

**Canonical document**: **[`docs/HANDOVER.md` on GitHub →](https://github.com/nucleus-data/nucleus/blob/main/docs/HANDOVER.md)**.

This page is the public-docs proxy. The canonical handover lives in the repository so it can be edited under the same review process as the rest of the codebase.

## What's in the handover

| Section | Purpose |
|---------|---------|
| **1. Mental model** | Re-read first when disoriented; product identity + 11 hard constraints + beachhead persona |
| **2. Daily (15 min)** | New issues + Discussions + CI status + `pip-audit` |
| **3. Weekly (1 h)** | PR review + Dependabot triage decision matrix + governance health |
| **4. Monthly (3-4 h)** | Drift detection prompt + LOC snapshot + license + dep audit + community health |
| **5. Quarterly (1-2 d)** | Upgrade audit + security review + roadmap phase-gate review |
| **6. Annual (1-2 wk)** | Major version planning + community deep-dive + sponsor relations + vision re-validation |
| **7. Crisis playbooks** | 8 scenarios — CVE, major version bump, hostile PR, license pivot, burnout, prod bug, HN surge, brand confusion |
| **8. AI workflow playbook** | Cursor surface guide + Boundary Map + hallucination discipline + LLM cost management + when NOT to use AI |
| **9. Solo OSS economics** | GitHub Sponsors + Open Collective + outreach template + Cloud tier timing + hiring signals |
| **10. Decision-making process** | When to ADR / when to defer / when to escalate |
| **11. Health metrics dashboard** | Manual, no automation — 11 metrics with healthy trends |
| **12. Final word** | Re-read when discouraged |
