## When NOT to send

- Do not send if `github.com/nucleus-data/nucleus` still returns 404 — testers cannot install the tool.
- Do not send if `[BOOK_30MIN_HERE]` is still a placeholder — you will lose sign-ups.
- Do not send before `[AMOUNT]` is confirmed — vague compensation reduces conversion by ~40% in user research contexts.
