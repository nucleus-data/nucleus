# Support

| Channel             | Purpose |
| ------------------- | ------- |
| Project docs        | Architecture, onboarding, errors, conventions — see `README.md` and `docs/onboarding/quickstart.md`. |
| GitHub Discussions   | Questions, patterns, stack help — asynchronous community Q&A (when Discussions are enabled). |
| GitHub Issues        | Bugs, feature requests with repro steps, structured wrap proposals — match an issue template where possible. |
| Security advisories | Vulnerability disclosure — prefer private **GitHub Security Advisories (GHSA)**; email fallback noted in `SECURITY.md`. |

For release process, constraints, and upgrade discipline, see `AGENTS.md` (implementation workflow and upgrade-safe design).
